# Direction C — 비판정본 (Critical Edition)

작성: ART_DIRECTION_BRANCH · 2026-08-31

공통 전제는 `A-instrument.md` §공통 전제 와 같다. 차이는 구조에서만 만든다.

---

## 1. 개념

**위계를 뒤집는다.** 주장이 본문이고 주석이 여백인 보통의 구조 대신,
**교정 장치(critical apparatus)가 지면의 절반을 차지하는 학술 정본**의 형식을 쓴다.

근거: 이 포트폴리오의 실제 차별점은 주장의 목록이 아니라 **주장을 걸러낸 장치**다.
형제 저장소에는 등급 원장(`ref/20_evidence.md`)이 있고, D 등급 29건이 삭제 대상으로
기록되어 있다. 그 원장이 존재한다는 사실이 어떤 성과 문장보다 강하다.

## 2. 이 방향의 결정적 장치 — 지워진 문장을 보여준다

지면에 **취소선이 그어진 문장**을 의도적으로 남긴다.

```
D7  ~~검색 응답 시간 95% 단축 (2초 → 100ms)~~     측정 산출물 없음
A   풀 스캔 대신 토큰 키를 직접 참조하도록 바꿨습니다   searchQuery.js:363
```

이전 이력서에 실제로 적혀 있었고, 근거가 없어서 스스로 지운 문장이다. 그것을 지운 자리에
남겨두면 방문자는 **이 사람이 자기 주장에 무엇을 요구하는지**를 3초 만에 안다.
이 사이트에서 가장 기억에 남을 요소가 될 가능성이 가장 높은 장치다.

## 3. 감정적 성격

엄격하고 약간 불편하다. 자기 검열의 흔적을 전시하는 것은 자신감의 표현이면서 동시에
위험한 자기 노출이다.

## 4. 시각 은유

비판정본 · 교정쇄. 본문 / 이문(異文) / 주석이 한 지면에 층으로 앉는 형식.

## 5. 타이포그래피

- 3층 조판: 주장(17px Sans) · 등급 기호(14px Mono, 좌측 정렬 고정 폭) · 근거(13px Mono).
- 취소선은 `text-decoration: line-through`, 두께 1px, 색은 `--ink-3`.
  **절대 빨간색을 쓰지 않는다** — 색으로 오류를 표시하면 색맹 독자에게 사라지고,
  경고처럼 읽혀서 "이 사람이 거짓말했다"로 오해된다. 등급 기호가 정본이다.
- 지면에서 가장 큰 글자는 등급 문자 `A` · `B` · `D` (32px Mono). 값이 아니라 판정이 크다.

## 6. 그리드

- 2열 비대칭 고정: 본문 62% / 교정 장치 38%. **비율이 절마다 바뀌지 않는다** —
  학술 정본의 신뢰는 서식의 불변성에서 온다.
- 좌측 34px 등급 기호 열이 항상 존재한다. 비어 있는 행이 없다.

## 7. 내비게이션

우측 교정 장치 열 상단에 등급 분포 요약(A n건 · B n건 · 지운 것 n건)이 sticky 로 붙는다.
그 숫자가 곧 목차 역할을 한다.

## 8. 프로젝트 서술

프로젝트마다 **주장 / 등급 / 근거 / 지운 문장** 4행 세트를 반복한다. 서사는 세트의
누적으로 만들어진다. YORR 는 세트 7개, FestiFriends 5개, Pookjayo 5개.

## 9. 이미지 처리

사진 0장. 취소선과 등급 기호의 반복 패턴이 텍스처가 된다.

## 10. 깊이 모델

깊이 없음. 층위는 활자 급수와 잉크 농도로만.

## 11. 배경 시스템

28px 괘선 유지. 교정 장치 열에만 `--ground-sub` 를 깔아 두 층이 다른 종이임을 표시한다.

## 12. 스크롤 철학

정독. 스크롤 위치의 함수인 속성 0개.

## 13. 시그니처 인터랙션

1. **등급 필터** — 등급 기호를 누르면 그 등급의 행만 남는다. 상태는 URL 쿼리에 남는다
   (FestiFriends 에서 본인이 쓴 URL 상태 패턴의 재현이므로 서사와 일치한다).
   CSS 소유, 위치 이동 없음, 320ms 정렬 전이는 Motion `layout`.
2. **지운 문장 펼치기** — 취소선 문장을 누르면 지운 사유와 대체 문구가 펼쳐진다.

## 14. 컴포넌트 후보

`EvidenceNote` · `DecisionIndex` (이미 구현) 가 그대로 주역. 신규는 `GradeFilter` 하나.
기성품 필요 없음 — 이 방향은 이 저장소에 이미 있는 컴포넌트와 가장 잘 맞는다.

## 15. 모바일 전략

교정 장치 열이 각 주장 **바로 아래로** 접힌다 (좌우 → 상하). 등급 기호는 주장 앞에 인라인.
취소선 문장은 320px 에서 2줄을 넘기면 접어 두고 "지운 문장 보기"로 노출한다.

## 16. 성능 위험

없음. 필터 정렬 전이만 Motion.

## 18. 이 방향의 치명적 위험

**오독 위험이 방향의 심장부에 있다.** 10~30초 리크루터는 취소선을 인지하지 못할 수 있고,
그러면 "검색 응답 95% 단축"을 이 사람의 주장으로 읽고 나간다. 즉 **거짓 주장을 하지 않기
위한 장치가 거짓 주장을 전파하는 장치가 된다.** 완화책(취소선 두껍게, 등급 기호 크게,
"지운 문장" 라벨 부착)은 모두 지면을 시끄럽게 만든다.

또한 지면 절반이 메타 정보이므로, 정작 **무엇을 만들 수 있는 사람인가**에 대한 답이
얇아진다. `DESIGN.md` §5 의 "완주하지 못한 것을 성장 서사로 포장하지 않는다"와는
어긋나지 않지만, 자기 검열의 전시가 성과의 전시를 밀어낼 수 있다.
