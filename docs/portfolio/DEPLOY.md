# 배포

## 지금 상태

배포되어 있지 않다. 이 문서를 따라 한 번 연결하면 그다음부터는 `main` 에 푸시할 때마다
자동으로 나간다.

- 호스트: **Vercel** (Next.js 를 만든 곳이라 App Router · 정적 프리렌더가 설정 없이 붙는다)
- 저장소: https://github.com/jadewisemann/portfolio
- 빌드 산출물: 전 라우트 정적. 서버 런타임도, 환경 변수도, 데이터베이스도 없다

## 한 번만 하는 설정

1. https://vercel.com 에 GitHub 계정으로 로그인한다.
2. **Add New → Project → Import Git Repository** 에서 `jadewisemann/portfolio` 를 고른다.
3. 프레임워크가 **Next.js** 로 자동 인식되는지만 확인하고 나머지는 **그대로 둔다.**
   빌드 명령 · 출력 디렉터리 · 설치 명령을 손으로 채우지 마라 — 비워 두면 Vercel 이
   Next.js 기본값을 쓰고, 그게 맞다.
4. 환경 변수는 **없다.** 넣을 것이 없다.
5. **Deploy.**

끝이다. `vercel.json` 을 두지 않는 것은 게으름이 아니라 선택이다 — Next.js 프로젝트에서
그 파일은 기본값을 덮어써야 할 때만 필요하고, 지금은 덮어쓸 것이 없다. 빈 설정 파일은
나중에 누군가 그것을 정본으로 착각하게 만든다.

## 이후 동작

| 무엇 | 언제 | 결과 |
|---|---|---|
| `main` 에 푸시 | 매번 | 프로덕션 배포 |
| 그 외 브랜치에 푸시 | 매번 | 프리뷰 배포 (고유 URL) |
| 풀 리퀘스트 | 열릴 때 | 프리뷰 URL 이 PR 에 댓글로 붙는다 |

**프리뷰 배포가 이 프로젝트에서는 특히 중요하다.** 이 사이트는 3D 씬이라 정지 스크린샷으로
절반밖에 판정할 수 없다. 스크롤 감각 · 시차 · 모바일 터치 · 실제 GPU 에서의 프레임 페이싱은
기기에서 만져 봐야 안다. 헤드리스 캡처는 SwiftShader 소프트웨어 렌더링이므로 **캡처의
타이밍 수치는 대표성이 없다.** 픽셀만 믿는다.

## 검증은 Vercel 이 하지 않는다

Vercel 은 `next build` 만 돌린다. 린트 · 타입 검사 · 단위 테스트 · E2E 는 돌리지 않으므로,
그것만 믿으면 이 저장소의 게이트가 전부 무력해진다. 그래서 `.github/workflows/ci.yml` 이
따로 있고 푸시와 PR 마다 다음을 돌린다.

```
npm run lint · npm run typecheck · npm test · npm run e2e · node scripts/graph.mjs doctor
```

배포는 CI 에서 하지 않는다. 배포 토큰을 저장소 시크릿에 둘 이유가 없고, 배포 경로가
둘이면 어느 쪽이 나간 것인지 추적이 안 된다.

## 도메인

기본으로 `*.vercel.app` 하위 도메인이 붙는다. 커스텀 도메인을 붙이려면 Vercel 프로젝트의
**Settings → Domains** 에서 추가하고 DNS 를 지시대로 맞춘다. 붙이고 나면
`docs/portfolio/CONTENT.md` §8 의 링크 표에 그 URL 을 등급과 함께 적는다 — 이 저장소에서는
화면에 나가는 모든 링크가 그 표를 거친다.

## 배포 전에 확인할 것

- `npm run build` 가 로컬에서 통과한다
- `npm run e2e` 가 통과한다 (프로덕션 빌드를 검증하므로 이게 진짜 배포 리허설이다)
- `public/shots/` 의 스크린샷에 팀원 실명 · PII 가 없다 (`CAPTURE_SHOTS.md` 의 가림 규칙).
  **이 저장소는 공개다.** 텍스트에 대한 금지는 `src/forbidden-claims.test.ts` 가 기계로
  검사하지만 **이미지 안은 아무도 검사하지 않는다.** 사람이 봐야 한다
