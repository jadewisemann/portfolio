# Component Research

Never begin with implementation. Search existing high-quality components first.

Sources, in order:

1. 21st.dev
2. React Bits
3. Aceternity UI
4. Magic UI
5. Codrops
6. Other reputable sources when justified

Search by interaction intent, not vague style terms. For every serious candidate, record its name, source URL, intended scene, interaction concept, dependencies, animation technology, license, performance risk, mobile suitability, accessibility concerns, required customization, and score.

Score visual impact (20), art direction (20), narrative usefulness (15), interaction quality (15), originality (10), mobile suitability (7), performance (5), accessibility (5), and integration risk (3). A score of 85+ is strong, 75–84 is fallback, and lower scores are rejected. Return a shortlist; do not install a candidate merely because it scores well.
