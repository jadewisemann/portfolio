# Art Direction

Create exactly three serious visual directions.

They must differ structurally.

Color swaps do not count.

For each direction define:

- concept
- emotional character
- visual metaphor
- typography
- grid
- navigation
- project storytelling
- image treatment
- depth model
- background system
- scroll philosophy
- signature interactions
- component candidates
- mobile strategy
- performance risk

Then score:

Storytelling
Memorability
Coherence
Originality
Technical expressiveness
Usability
Mobile viability
Performance viability

Select ONE winner.

At most one major idea may be borrowed from a losing direction.

Do not create an averaged compromise.
