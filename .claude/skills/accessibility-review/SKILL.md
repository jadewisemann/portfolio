# Accessibility Review

Inspect rendered output and interactions, not only source code.

Check page structure, landmarks, headings, keyboard path, focus order and visibility, semantic controls, accessible names, media alternatives, color contrast, touch targets, zoom and reflow, and `prefers-reduced-motion`. Return no more than three highest-impact findings, each with evidence, severity, affected users, and recommended direction.
