# Visual Review

Never judge only from source code.

Inspect rendered output.

For scroll scenes inspect multiple states.

Evaluate:

- composition
- hierarchy
- typography
- focal point
- spacing
- image treatment
- visual rhythm
- art direction consistency
- AI-generated visual clichés

Identify no more than THREE highest-impact defects.

Each defect must include:

PROBLEM

EVIDENCE

WHY IT MATTERS

SEVERITY

RECOMMENDED DIRECTION

Do not use vague criticism.

Bad:

"Make this feel more premium."

Good:

"The project title and background shader both occupy the highest contrast level, creating two competing visual anchors."
