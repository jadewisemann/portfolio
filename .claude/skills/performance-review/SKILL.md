# Performance Review

Inspect real builds and rendered behavior. Do not infer performance solely from component names or source-code style.

Check loading path, image and video payloads, font loading, bundle cost, long tasks, layout shift, scroll and animation frame stability, WebGL lifecycle, cleanup, mobile behavior, and reduced-motion cost. Return no more than three highest-impact findings, each with evidence, severity, likely cause, and recommended direction.
