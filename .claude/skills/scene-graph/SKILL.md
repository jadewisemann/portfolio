# Scene Graph

Turn the selected art direction and motion language into a concrete scene sequence before implementation expands beyond the golden slice.

For each scene, define its narrative role, primary focal point, source content, entry and exit transition, motion owner, responsive behavior, reduced-motion fallback, dependencies, and acceptance criteria. Record scene order and transitions in `docs/portfolio/SCENE_GRAPH.md`.

Do not add a scene solely to demonstrate an effect. Keep visual systems consistent with the locked art direction and avoid duplicate storytelling.
