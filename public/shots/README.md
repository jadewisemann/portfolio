# 스크린샷 두는 곳

소유자가 여기에 넣으면 사이트가 집어 간다. 파일명은 자유다.

```
public/shots/yorr/          모바일 위주 — 휴대폰이 컨트롤러인 게임 플랫폼
public/shots/festifriends/  데스크톱 · 모바일 섞임
public/shots/pookjayo/      모바일 우선 제품
```

## 지켜야 할 것

- **원본 해상도 그대로.** 3D 평면에 텍스처로 올라가므로 기울면 축소본이 뭉갠다.
  화면에 작게 보인다고 미리 줄이지 않는다.
- **PNG 또는 WebP.** JPEG 는 UI 스크린샷의 글자 가장자리에 링잉을 만든다.
- **파일명에 `mobile` 또는 `desktop` 을 넣는다.** 배치가 기기 종류로 갈린다
  (9:19.5 대 16:10). 없으면 가로세로비로 추정하는데, 추정은 틀릴 수 있다.

## 넣기 전에 지울 것

이 저장소는 **공개**다. `CONTENT.md` §9 와 `HANDOFF.md` §7 이 금지한 것들이
스크린샷 안에 찍혀 있으면 그대로 공개된다.

- 팀원 실명 · 프로필 사진 · 이메일 · 전화번호
- 실제 사용자 데이터, 결제 정보, 토큰이 보이는 URL
- 소속 기관 내부 용어

가려야 하면 잘라내거나 덮는다. 블러는 쓰지 않는다 —
`DESIGN_SYSTEM.md` §2 가 금지하고 기계 검사가 잡는다. 그리고 블러는 되돌릴 수 있다.
